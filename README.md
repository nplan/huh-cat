# HUUUH?

**[huuuh.meme](https://huuuh.meme)**: Ben the Huh? Cat, but you're the sound engineer.

1. Pick a cat. 🐱
2. Pick a mood: confused, shocked, annoyed, suspicious, scared... huh?
3. Tune the huh: pitch, length, how much of a question it is, even the vowel. *Huuuuh?*
4. Share the link or download the video. Inflict it on your group chat.

Every mood has its own link, e.g. [huuuh.meme/annoyed](https://huuuh.meme/annoyed). Sound nerds get a whole [lab](https://huuuh.meme/lab) with every knob. And one of the moods is hiding something. Tap twice, if you dare. 🤢

No build, no tracking cookies, just a static page and a very confused cat.
Run it locally: `npx serve public`. Dev notes: [docs/DEVELOPING.md](docs/DEVELOPING.md). Clips, sounds, fonts and licences: [CREDITS.md](CREDITS.md).
